# 产品方向备忘 · 标注数据用于 AI 训练

> 用户确认的**方向**（非当前任务）。本文只记设计取舍，供以后立项时参考。**暂不实现**。

## 为什么值得做

Annota 的标注是**强结构化多模态对齐数据**，比纯文本语料稀缺：

- `box`（画面归一化区域）+ `t`/`dur`（时间锚点）+ `word`/`label`/`tags`（词义）
- `quote`（文章文本锚点）→ **视频帧 ↔ 词 ↔ 时间 ↔ 文本** 四元对齐
- provenance（谁标的、属哪个组、何时、公开/私有）

可支撑：视觉-语言对齐 / 指代定位（phrase grounding）、视频时序事件标注、动作-语言预训练、
领域术语抽取（本项目主线「边看边标词」天然产出）。

## 三条硬约束（不满足就不做）

1. **授权**：把用户标注用于训练需**明确、独立的授权**，不能一句模糊提示糊过去。
   贡献时单独勾选「允许用于模型训练」，与「私密 / 仅组内」区分。
2. **隐私与权属**：标注常带媒体 URL / 标题 / 文章原文。训练用途可能涉第三方版权
   （如 B 站视频画面）。坚持项目既有原则：**不搬媒体本体，只搬标注指针**（box/t/word/quote）。
3. **可达性**：标注现散在各用户 localStorage / 各组自建 CloudBase，**项目方拿不到**。
   要成资产必须有一条**自愿汇集**通道，绝不偷偷抓。

## 建议路径：opt-in「公共标注数据集」

- **开关**：设置里「把**公开组**的标注贡献到公共数据集」，**默认关**；**私有组永不上传**。
- **许可层**：每条贡献打 license（如 CC-BY）+ 授权范围 + 可撤回标记。
- **标准导出**：JSONL / COCO-style / WebVTT+annotation 等，可直接喂训练管线。
- **激励**：署名 / 积分（identity 体系与署名能力已具备）。
- **文案（贡献入口处，非角落）**：
  「你标注的公开内容将被用于改进模型，可随时撤回。」

## 明确不做

- **不加**「数据可能用于提升」这类模糊提示——当前数据根本没外流，加了反而误导且法律不足。
- **不做**默认采集 / 隐式回传。
- **不做**遥测收集标注内容（若要遥测，只发匿名版本/崩溃指标，默认关、可关、可查）。

## 触发时机

等浏览器端体验（M4/M5）稳定、且有真实的公开组使用量后再立项。
