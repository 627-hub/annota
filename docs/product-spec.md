## 0. 一句话

给「别人的内容」加一层**好看、顺手、可共享**的标注：打开即用（标注浏览器）、暂停即标（单条 ≤6 秒）、
随时带走（数据属于标注者）；媒态从视频扩展到图片 / 网页文章 / 文档，形态从工具生长为**内容之上的社交标注层**。

## 2. 定位与原则

### 2.1 定位陈述

- **一句话定位**：内容之上的社交标注层——别人的内容不动，只加一层可共享的标注。
- **市场**：语言学习（首个场景）× 知识工作者（引用与语境笔记）× 数据标注（众包与 AI 建议）。
- **差异化**：竞品要么搬媒体（合规风险），要么是纯工具（无积累）。我们**只存标注**（W3C Web Annotation），
  数据归标注者、可导出自持、可去中心化交换——「轻协议 + 文件」，类比 Anki 牌组 / uBlock 列表 / git。
- **终局**：众包标注训 JEV 式 word↔region 决策模型（spec.md §9，不变）。

### 2.2 产品原则（所有设计决策的裁决标准）

1. **内容是主角，我们是玻璃层**——UI 静默认（播放中不打扰），交互时才显形；玻璃拟态叠在媒体上。
2. **三次点击、两个按键**——任何主操作 ≤3 次点击或 ≤2 次击键路径可达；键盘与触控并重。
3. **数据属于标注者**——随时全量导出；删除即真删；服务端只存标注与笔记产物。
4. **只加一层，不搬一块**——合规即设计：不存媒体、发现页不展示媒体本体、每条标注带 creator + license。
5. **AI 提议，人终审**——视觉语言固定：**虚线 = AI 建议，实线 = 人确认**；AI 不做写操作终审。

## 3. 目标用户

| 画像 | 场景 | 痛点 | 我们给的价值 | 频次预期 |

## 5. 设计系统（Design System）

### 5.1 设计约束（先认账，再设计）

- **注入式 UI**：叠层/Dock/面板/编辑器全部注入第三方页面 → 必须 Shadow DOM 样式隔离、
  CSS 全内联（不用外部字体/图标 CDN）、自带 z-index 层级、容忍宿主 CSP 与滚动劫持。
- **页面态 UI**（起始页/我的库/发现/设置/工作台）无上述约束，自由度完整。
- 深色优先：媒体消费场景以深色为主，玻璃拟态是自然解。

### 5.2 品牌与命名（已定：Annota）

**产品名：Annota**（annotation 去后缀形，好记、可双形）；中文语境全称「Annota · 标注浏览器」。
logo 方向：字母 A + 框选四角括号。仓库/域名重命名可行性见 §16。

### 5.3 Design Tokens（默认值，待品牌化后微调）

| 类 | Token | 值 |
|---|---|---|
| 强调色 | `--va-accent` | `#F5A623`（琥珀；用于框选、我的标注、主按钮——与 B站粉/YouTube红/抖音霓虹青都不撞） |
| 类型色 | word / comment / question / ai | `#F5A623` / `#38BDF8` / `#A78BFA` / 灰白虚线 |
| 注入态玻璃 | bg / border / blur | `rgba(17,19,23,.78)` / `1px rgba(255,255,255,.08)` / `blur(20px) saturate(160%)`；阴影 `0 8px 32px rgba(0,0,0,.4)` |
| 注入态文字 | 主 / 次 / 弱 | `#F4F5F7` / `#A6ACB5` / `#6E747D` |

### 5.4 明暗与平台适配

- 主题：跟随系统 / 强制深 / 强制浅（设置中）；注入态默认深色玻璃（媒体上永远可读）。

- 窄屏（<768px）：Dock 贴边收缩为 40px 圆钮；面板转 bottom sheet（70vh）。

## 6. 界面规格（逐屏）

### 6.1 视频叠层与热区（C2）

- 作用域：活跃窗 `[t−0.15, t+dur]` 内的标注框。
- **播放中**：热区透明（不打扰，原则 1）；hover 显形（0.9）。
- **暂停 / 标注模式**：全部显形（0.95）：1.5px 实线 accent 框、圆角 4px、左上 18px 玻璃序号徽标。
- 徽标学习态：已收词的条目徽标淡化（学习进度轻可视）。
- **他人标注**：虚线 + 来源信任色点；**AI 建议**：灰白虚线 + 「AI」chip + 置信点（1–3 点）。
  → 全站固定「虚线=建议，实线=确认」视觉语言（原则 5）。
- 悬停任意框 → tooltip（词 + 释义 + 来源）；点击 → WordCard（C6）。

### 6.2 GlassDock（C1）

```
收起态：右下角 48px 玻璃圆钮（logo，呼吸动画仅引导期）
展开态（hover / 快捷键 / 点击展开）：
[ 标注 ▸ ] [ 词表 ] [ 同步⇄ ] [ AI ▸ ] [ ⋯ ▸ ]
```

- 位置：默认右下 24px；**可拖拽换位**、位置记忆；小屏贴边。
- 避让：展开方向自动翻转避开视口边与平台控件（如 B站右下弹幕设置）。
- 分组次级菜单（popover，玻璃）：
  - `标注 ▸`：框选标注 / 轨迹标注（R5）/ 关闭叠层
  - `AI ▸`：问 AI（MCP，默认）/ 发豆包（剪贴板 fallback）/ 截图 / AI 找词（R3）/ 存笔记
  - `⋯ ▸`：导入导出 Pack / 诊断（原 ⓘ 面板收编于此）/ 设置
- 状态徽标：未同步条数 badge；同步中 spinner；完成 ✓ 淡出 800ms。
- **环境感知**：检测到 `<video>` 显视频组；`<img>` 显图片组（R2）；文章页显划线组（R2）；
  无可标媒体 → Dock 隐藏（不装看不见的东西）。

### 6.3 EditorCard（C3，标注编辑卡）

```
EditorCard（约 304px，玻璃卡，框选松手后现于框的右上，视口边缘自动翻转）
├ 词输入（autofocus）
├ 释义 + 词性行（选填，留空合法——词本身即可成标注）
├ 查词行（词典外链带词开新页：[剑桥] [有道] [欧路] …；默认词典设置里配）
├ 时间行： t = 12.40（mono）· dur chips [0.5 | 1 | 2 | 3]s · [用当前]图标钮
├ 迷你时间轴 scrubber（拖动改 t，即时预览）
└ 底部：[取消]  [保存并播放 ⏵]（主按钮 = accent）
```

- 键盘：`Enter` 保存并播放 / `Esc` 取消 / `Tab` 切字段。
- 词库联想已下线（决策 A3）：词必填、释义/词性选填，动线更轻；后续可接免费在线词典 API（opt-in + IndexedDB 缓存）恢复自动填。
- 保存反馈：新框 flash 160ms + toast（可关）。
- 编辑已有标注：点热区 → WordCard → 「编辑」进同一 EditorCard（复用）。
- **动线目标**：暂停 → `D` → 框选 → 输入 → `Enter` = 2 次击键 + 1 次拖拽，中位 ≤6s。

### 6.4 SidePanel 词表面板（C4）

```
SidePanel（右缘抽屉 360px；窄屏 bottom sheet 70vh；开合：Dock「词表」/ ⌥L）
├ 顶部：搜索框（面板内 / 聚焦）
├ Tabs：[时间轴] [生词本] [来源]
│   时间轴：按时间分组列表；条目 = 序号chip + 词(bold) + 释义(次色单行) + 时间码chip(mono)
│           点击 → seek(t) + 框 flash；悬停 → 对应框高亮；行内菜单 = 编辑/删除/收词/发豆包
│   生词本：按词聚合（词 × 出现次数 × 最近媒体）；导出 Anki / CSV / JSON
│   来源：我的 / 他人（来源列表 + 每源信任开关）/ AI 建议待确认
└ 空态：「这个视频还没有标注 — 按 D 框选第一个词」（一句话 + 一个动作）
```

### 6.5 TimelineStrip 标注密度条（C5）

- 2px 细条叠在平台进度条正上方；每条标注 = 一道刻痕，密集区渐变加粗。
- hover：tooltip（词 + 时间码）；点击：seek。
- 平台进度条定位失败（generic）→ 回退渲染在 SidePanel 顶部。R1 只做 bilibili / youtube，其余回退。

### 6.6 起始页（新标签页，Tauri 浏览器旗舰）

```
├ 顶部：居中搜索/地址框（640px）
├ 区块「继续标注」：最近媒体卡片（平台标 · 标题 · N 条标注 · 上次时间码 chip）→ 点击直达原页并 seek
├ 区块「我的生词」：今日词卡 ×3（有 SRS 下游则接到期；无则最近标注词；点击回看原视频那一帧）
├ 区块「发现」：热门 Pack 卡（R4 上线前隐藏）
├ 工具行（常驻）：查词词典外链集（默认词典可配）· demo「先试玩」
└ 角落：同步状态点 · 设置 · 数据工作台
```

- 新用户空态（**冷启动 = 决策 A2**）：三步卡（看个视频 → 框个词 → 导出词包，逐步打勾）+ 「先试玩」demo + 查词工具行；无假推荐、无占位假卡片；有数据后区块才长出（继续标注 → 我的生词 → 发现）。
- 性能：本地数据（IndexedDB 汇总），首帧 <100ms。

### 6.7 我的库（媒体与标注管理）

```
我的库（页面态；Electron 内嵌 + 服务端 /library 同一套）
├ 左栏 280px：媒体列表（按最近）；顶部 tabs [视频 | 图片 | 文章] + 搜索
├ 右区：选中媒体详情
│   ├ 头：标题 · 链接 · N 条标注 · [打开原页] [导出 Pack] [删除]
│   ├ 标注表：可排序（时间/词/创建时间），行内编辑，批量勾选（导出/删）
│   └ 生词视图：词聚合 + 频次 + [导出 Anki / CSV / JSON]
└ 窄屏：单栏切换（列表 → 详情）
```

### 6.8 发现页（R4）

- 卡片流：Pack 卡 = 标题 + **词云摘要**（设计重点：没有媒体缩略图的合规卡片）+ 平台标 + 标注数 + 作者 + 订阅数。
- 订阅 → Feed 拉取 → 自动合并（幂等）；信任管理入口。
- 合规红线：不展示媒体本体；卡片视觉靠词云 + 类型色带撑。

### 6.9 设置

- 分节：外观（主题 / 强调色预设 ×3）/ 同步（地址、**自动上传（标注后 5s 去抖）**、**自动下载（打开媒体时）** 开关、通道状态、配对码 QR）/ 词典（默认外链 + 自定义 `{word}` 占位模板；可选「在线查词 API」开关）/ AI（豆包配置检测、截图质量）/ 笔记（NOTES_DIR、格式）/ 快捷键（可改键）/ 数据（**导出全部**（Pack + data.jsonl）/ 清空）/ 关于。
- 诊断（原 ⓘ 面板）收编为「设置 → 诊断」，开发者模式开关后才显示。

### 6.10 数据工作台（R3，`/console`）

- 总量卡：标注数 / 媒体数 / 词数 / 累计天数。
- 图表：按媒体 top 条形 / 词频 top 表 / 标注时刻分布；（R5 前）标注者一致性（IoU ≥0.6 重合率）热图。
- 导出：训练集 JSONL（schema 对齐 spec.md §9.2 三原语任务）、CSV、Anki。
- 定位：让「数据引擎」可见可用（HANDOVER §8.1 的产品化）。

### 6.11 OnboardingTour（C8，触发式引导）

- **不做一次性说明书**。三条触发气泡，各自完成即消：
  1. 首次进入可标媒体 → Dock 圆钮生长动画 + 气泡「这个视频可以标注 — 按 D 或点标注试试框选一个词」。
  2. 首次框选拖动时 → EditorCard 内嵌一行提示「填词后 Enter 保存」。
  3. 完成第一条标注 → toast「已保存！你的第一条标注」+（次日首次打开时）提示「⇄ 同步可推送到手机」。
- 每条气泡带跳过；`localStorage` 记忆；设置 → 帮助 → 重看引导。

### 6.12 移动观看端

- 热区 → 点按弹 **WordCard bottom sheet**：词大字 + 释义/词性（有则显）+ [⏮ 回看 3s] [查词→默认词典] [收词]；按钮拇指区可达。
- 打开即自动同步（已有）；M2 标注降级：长按 → 十字准星拖框（精度不足时用「四角微调柄」补）。

### 6.13 AI 陪练交互（MCP 优先，豆包剪贴板兜底）

- **主路径：MCP server**。本地服务同时是一个 MCP server；用户把 Annota MCP 接到 Claude Desktop / Hermes / 任意 MCP host。
  Dock「AI ▸ → 问 Claude/Hermes」：宿主 agent 可调 tools（`capture_frame`、`words_at`、`save_note`、`suggest_boxes` 等），无需手动粘贴。
- **次路径：剪贴板桥（发豆包）**。一键打包「截图 + 平台/链接/标题/进度/已标词」进富剪贴板 → 桌面豆包粘贴即问；
  仅用于无法接 MCP 的豆包 GUI（现状保留，降为 fallback）。
- 反馈：MCP 调用审计面板（每次 tool call 可展开查看/撤销写操作）；剪贴板路径 toast「已复制，去豆包粘贴（⌘V）」+ 截图预览 1.5s。
- `ai ▸` 组内并列：问 AI（MCP）/ 发豆包（fallback）/ 截图 / 存笔记（NOTES_DIR → Obsidian + data.jsonl 沉淀）。
- `/api/chat` 不进 UI（保持：agent loop 经 MCP 实现，见 §10）。

## 7. 交互与操作细节

### 7.1 快捷键（默认，全部可改键）

| 场景 | 键 | 动作 |
|---|---|---|
| 全局（带修饰键，避免与平台冲突） | `⌘K` / `⌥L` / `⌥S` | 命令面板 / 词表面板 / 叠层显隐 |
| **标注模式**（点「标注」或按 `D` 进入，Esc 退出；模式指示 = Dock 高亮 + 光标十字） | `D` | 直接框选 |
| | `Space` | 暂停/继续（模式内接管） |
| | `←/→`（`Shift` 细调 ±0.2s） | t ∓/±1s |
| | `Tab / ⇧Tab` 或 `↑/↓` | 上一/下一标注（seek + flash） |
| | `Esc` | 取消框选 / 退出模式 |
| EditorCard 内 | `Enter / Esc / Tab` | 保存续播 / 取消 / 切字段 |
| SidePanel 内 | `/` | 聚焦搜索 |

> 裸单键**只在标注模式激活时**生效（B站 `D`=弹幕、空格=播放等平台冲突全靠模式域隔离）。

### 7.2 指针与触控

- 热区：hover 高亮 + tooltip；单击 = WordCard；双击 / 长按 = 直接进编辑。
- 框选：自由矩形 + 8 柜柄微调 + `⌥` 拖动整体；松手 → EditorCard。
- 移动端：长按进入框选；WordCard 全 bottom sheet；Dock 贴边收缩。

### 7.3 无障碍

- 全控件 `aria-label` + `role`；键盘全可达（命令面板即键盘路径的同源保障）；焦点环 accent 2px offset 2px。
- 类型色不作唯一区分：徽标形状编码（圆=词 / 方=评论 / 三角=提问）。
- `prefers-reduced-motion` 关全部动效；面板对比度 ≥4.5:1；注入态（媒体上）用描边+玻璃保证可读。
- 词卡字号 ≥14；时间码 mono 防误读。

### 7.4 反馈与空态

- 同步结果**必须可见**：toast「同步完成：拉取 5 · 合并 12 · 冲突 2 已保留双方」→ 详情可展开（IoU/词对比表）。
- 一切异步操作（同步/截图/笔记/AI）有即时态（spinner/玻璃变暗）+ 终态（✓/✗ + 重试）。
- 空态三件套：线条插画（单色）+ 一句话 + 一个动作按钮；禁止裸「暂无数据」。

## 10. AI 能力产品化（MCP server 优先，豆包剪贴板兜底）

本地服务同时作为 **MCP server**（stdio / SSE 双形态，兼容 Claude Desktop 与 Hermes）。暴露的 tools：
- `capture_frame(mediaId, t)` → 当前帧截图（base64 PNG）+ 元数据
- `list_annotations(mediaId)` / `words_at(mediaId, t)` → 标注数据
- `save_note(mediaId, title, content)` → 写 Obsidian 笔记 / data.jsonl
- `suggest_boxes(mediaId, t, candidates)` → AI 找词候选框（R3）

| 能力 | 形态 | 期 |
|---|---|---|
| **MCP server（本地服务）** | 暴露 tools；Claude Desktop / Hermes / 任意 MCP host 连接 | R1 |
| 上下文桥（剪贴板） | 「发豆包」一键打包 → 桌面豆包粘贴；无 MCP host 用户的 fallback | — |
| **AI 找词（/suggest）** | 暂停 → Dock/palette「AI 找词」→ 候选框流（云开放词表）→ `Tab` 逐个、`Enter` 确认 | R3 |
| **agent loop** | 方舟 API + function calling；UI = SidePanel「AI 会话」；**写操作必须确认** | R3 |
| 豆包 GUI 自动化桥 | 不做主力（易碎），仅实验 | 不投 |

> MCP 让 agent「看得见画面、读得懂标注、写得进笔记」，比剪贴板少一步粘贴，且调用过程可审计（原则 5）。

- 通用聊天不自建（原则不变）；`/api/chat` 保留为动作型 AI 与 agent loop 底座，不上 UI。
- 建议框质量闭环：确认/弃置行为写入 data.jsonl → 反哺 Score 头（spec.md §9.2）。

## 11. 数据、账户与隐私

- **本地优先**：无账号可用全部功能（单人 + 局域网共享已覆盖 P4 场景）。

## 14. 成功指标

- **北极星**：每周新增确认标注数（AI 建议确认的计 0.5 权）。
- 激活：安装 → 首条标注转化 ≥60%，中位耗时 ≤3 min。
- 效率：单条标注中位 ≤6s；编辑器内纯键盘路径占比 ≥40%（埋点，默认关，用户显式开启）。
- 留存：P1 学习者 7 日回访 ≥30%。
- 共享：周内导出/同步过 Pack 的用户占比 ≥25%。
- 质量：多源合并后 IoU ≥0.6 一致率（数据工作台可视化）。
- 满意：R1 走查 NPS ≥4/5（10 人样本）。

## 17. 决策记录

**v1.1（2026-10-01）**
- **A1 产品名：Annota**（§5.2）。
- **A2 起始页冷启动**：本地三步卡 + 「先试玩」demo + 查词工具行；无假推荐、无占位假卡（§6.6）。

- **A6 桌面壳 R1 切 Tauri**（§12 / §13）：10MB 安装包作为核心卖点优先；Electron 保留为 R1 blocker 时的备选。
  截图/富剪贴板按平台 native API 实现。
