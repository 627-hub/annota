## 3. 真机验收发现并修复

- **整窗截图**：`core.captureFrame()` 的 Tauri 分支漏了 `cropDataUrl`（裁剪只写在扩展分支）→ 三通道统一 `cropToMedia` + 超时保护（超时返回 `null`，不泄整屏）。
- **截图时机**：跳转后等 2s、每条间隔 1.2s、截前 pause → **升级为手动确认模式**（跨域/遮罩下自动截帧不可靠）：
  - `seek(t + 0.15)`（提前量：`isVisible` 有提前浮现 + 落帧延迟，直接 seek 会"框滞后/停在上一条"）+ pause + `renderOnly` 单条框；
  - 确认条：带**实时时间码**、「回到标注点」、「截图」（Enter）、「跳过」（Esc）；
  - 用户手动拖过画面 → **以当前帧为准回写 `t` + `updated`**（所见即所得），并 `save()`。
- **导出文件名**：`annota_<视频号>.apkg`（不再把中文 deck 名洗成下划线）。
- **卡片格式**：正面=单词；背面=词 + 截图 + 释义/词性 + 来源；标签=固定 `annota` + 用户选的语言学习类 tag（过滤杂 tag）。

## 4. OCR 代码审查 + 修复

`ocr` 配置修好（`api_key_cmd = sec get "$(ocgo active)"` 动态跟随 `ocgo`；删静态 key 与坏模型 `hy4-preview`）。审查 24 文件 / 35 条，**critical/high/medium 全修**：

**High**
- Rust `tagstr` 未转义 → Anki 卡 HTML 注入（XSS）→ 加 `esc()`（与 Python 对齐）。
- `displayVersion` 本地新建/编辑/删除/导入不重置 → `syncNow` 会丢本地改动 → 全部置 `local`。
- `cropToMedia` 超时回落**整窗图** → 改返回 `null`（退纯文字卡，绝不泄整屏）。
- `reconcileOnOpen` 延迟/弹窗期间会覆盖用户**在途编辑** → 指纹变化即放弃覆盖；切媒体中止。
- `.tmp/<deck>/cards` 从不清空 → 同媒体二次导出残留旧卡 → `idx==0` 清批（Python + Rust）。
- **生成物烧内网 IP**：`build.py` 默认**发布构建空 URL 列表**；本地零配置调试改由 `dev/hub.py` 传 `ANNOTA_LOCAL_SYNC=1` 显式开启。

**Medium**
- 三处 `same()` 纳入 `tags`（纯标签标注不被误并）。
- `fingerprint` 纳入内容（老数据无 `updated` 也能判差异）。
- `syncNow` 未与服务端确认对齐时**不整包替换**（退增量合并推送，不误删）。
- 冲突/覆盖弹窗支持 Esc / 点外部关闭（Promise 不再悬空）。
- console：分批拉取（每批 8）、`rows` 复位、CSV 加 BOM。
- `export.js`：`jsonl` 改为真正逐行 JSONL；进度 pill 关闭后复位；canvas 路径真提示。
- `index.html`：导出按钮 in-flight 防抖；hash 改追加（保留原锚点）。
- `apkg`：note/card id 加随机基数防跨次撞；model `did` 指向真实牌组；corrupt 卡计数上报；连接异常路径关闭。
- Rust `has_shot` 仅在截图文件确实可读时为真（避免 `<img>` 指向不存在媒体）。
