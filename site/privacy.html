隐私政策

最后更新：2026-10-09

Annota 默认在你的电脑上运行。本页说明哪些数据留在本机、哪些数据会在你主动使用组功能时上云，以及我们不做什么。

一、我们不做什么

  • 无遥测：不收集使用统计，不向开发者回传任何使用数据。
  • 不自动上传：标注、截图、剪贴板内容与崩溃报告都不会在未经你确认的情况下离开本机。

二、数据保存在本机

  • 标注数据：保存在本机的标注 store（标注数据目录）。
  • 本地数据库：annota.db 保存标注索引与历史记录等元数据。
  • 备份：应用数据目录 backups/ 每日一份，保留 7 份。
  • 运行日志：macOS 位于 ~/Library/Logs/annota。日志只在本机保存。
  • 偏好设置：同步地址、快捷键、词典模板与信任站点列表，由本地服务保存在本机。

三、组数据与云端

个人标注库只保存在本机。只有当你主动创建或加入组，并选择共享方式时，组内标注才会离开本机：

  • 云开发组：组内数据存放在腾讯云开发（CloudBase）中，加入组需要登录。
  • Git 仓库组：组内数据写入你指定的 GitHub 或 Gitee 仓库，仓库访问令牌由你自行保管。

四、AI 助手的 API key

如果你在设置中填写模型服务的 API key，它只会保存到本机的系统钥匙串，不会写入设置文件，也不会上传到任何服务器。清除后，钥匙串中的记录会被删除。

五、崩溃报告

崩溃报告默认只写入本机日志。若你希望把报告发送给开发者以便排查问题，每次都需要你在界面中明确确认，不会自动发送。

六、变更与联系

本政策如有变化，会更新本页顶部的日期。对本政策有疑问，请到 GitHub Issues 反馈。
